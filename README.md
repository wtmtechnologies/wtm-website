# downloadwtm.com

Static marketing + legal site for **WTM (What's the Move?)** by WTM Technologies LLC.

Plain HTML/CSS, no build step. Deployed on Netlify (connect this repo, publish dir = root).

- `index.html` — overview
- `business.html` — for business
- `legal.html` — Terms of Service + Privacy + Community Guidelines
- `contact.html` — contact / legal notices
- `styles.css`, `fonts/`, `assets/`
